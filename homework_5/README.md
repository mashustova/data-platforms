# ETL с Prefect и Spark

Prefect загружает данные в HDFS, запускает Spark на YARN и проверяет сохраненную таблицу через Hive.

## Окружение

Ubuntu 24.04, Python 3.12, Prefect 3.4.10, Spark 4.1.0, Hadoop 3.4.0, Hive 4.1.0, Bash, sudo без пароля. Используются работающие HDFS, YARN и Hive из предыдущих работ.

| team-17-en | 10.17.0.10 | Prefect и драйвер Spark |
| team-17-nn | 10.17.0.11 | HDFS, ResourceManager, Hive |
| team-17-00 | 10.17.0.12 | DataNode, NodeManager |

Скрипты выполняются на edge пользователем `team`. Spark работает от `hadoop` через sudo. Для Spark и Hive используется Java 17, для команд HDFS и YARN - Java 11.

С edge нужен доступ по SSH к внутренним узлам с ключом `~/.ssh/team_internal`. Имена узлов и ключи хостов уже настроены на стенде.

## Установка

На edge от `team`, в папке `/home/team/mashustova/homework_5`:

```bash
cd /home/team/mashustova/homework_5
bash scripts/install_prefect.sh
```

Создается отдельное окружение Python с закрепленными зависимостями. На team-17 оно уже установлено. Если в новой установке отсутствует `venv` или `ensurepip`, на edge от `team`:

```bash
sudo apt-get install -y --no-install-recommends python3.12-venv
```

После установки пакета повторяется команда установки Prefect.

## Запуск

В первом терминале на edge от `team`:

```bash
cd /home/team/mashustova/homework_5
bash scripts/server.sh
```

Сервер Prefect слушает `127.0.0.1:4200`. История запусков сохраняется в `~/.local/state/team17-hw5/prefect`.

Во втором терминале на edge от `team`:

```bash
cd /home/team/mashustova/homework_5
bash scripts/run.sh
```

Имя запуска создается автоматически. Его можно задать явно:

```bash
bash scripts/run.sh --run-id r20261120_02
```

Для каждого расчета используется новое имя: первая буква - строчная латинская, далее строчные латинские буквы, цифры и `_`, всего до 48 символов. Одновременно выполняется один поток.

| Задача | Действие |
|---|---|
| preflight | Проверка служб, клиентского окружения и ресурсов |
| stage_input | Загрузка CSV в HDFS |
| spark_etl | Расчет Spark в режиме YARN client |
| verify_result | Проверка статуса YARN, файлов и таблицы Hive |

Исходные данные содержат 15 заказов за три даты. Spark читает CSV с явной схемой, оставляет завершенные заказы с положительным количеством товара, вычисляет выручку через `DECIMAL` и группирует строки по дате и городу.

Результат сохраняется в Parquet через `partitionBy('dt').saveAsTable(...)`. Таблица регистрируется в общем Metastore. Для примера выше ее имя - `dp_mashustova_hw5.daily_sales_r20261120_02`.

Память драйвера на edge - 512 МБ. Для одного executor выделены 1 ядро, 512 МБ heap и 384 МБ дополнительной памяти; для ApplicationMaster - 256 + 256 МБ. При текущем минимуме YARN оба контейнера округляются до 1024 МБ. Перед запуском проверяются физические ресурсы двух рабочих узлов и не менее 1536 МБ доступной памяти на edge.

## Проверка

Spark читает сохраненную таблицу и Parquet, сравнивает результат с эталоном и завершает работу. Затем проверяются `SUCCEEDED` в YARN, `HEALTHY` в HDFS и все строки и партиции таблицы через Beeline. Поток и четыре задачи Prefect должны иметь статус `Completed`.

Повторная проверка выполненного запуска на edge от `team`:

```bash
cd /home/team/mashustova/homework_5
bash scripts/check.sh r20261120_01
```

Для этой команды нужен сохраненный рабочий каталог `results/r20261120_01/`. В новой копии сначала выполняется расчет с новым именем. Проверка не пересчитывает данные. Отчеты сохраняются в `results/`; эта папка исключена из Git.

При ошибке следующие задачи не выполняются, автоматических повторов нет. Расчет ограничен 600 секундами. Очистка завершает только приложение текущего запуска, проверяя его имя и владельца; данные и таблицы сохраняются.

Для проверки и завершения своего неудачного запуска, на edge от `team`:

```bash
bash scripts/cleanup.sh r20261120_02
```

## Интерфейс Prefect через SSH

- Сервер Prefect работает на edge во время просмотра истории.
- На локальном компьютере используется SSH-ключ с доступом к стенду.
- Терминал с туннелем остается открытым; при занятом порте сначала закрывается прежний туннель.

```bash
ssh -N -i ~/.ssh/team17 -o IdentitiesOnly=yes -o ExitOnForwardFailure=yes \
  -L 127.0.0.1:4200:127.0.0.1:4200 team@178.236.27.243
```

В браузере компьютера открывается `http://127.0.0.1:4200`. После просмотра сервер останавливается через `Ctrl+C` в первом терминале на edge. История сохраняется.
